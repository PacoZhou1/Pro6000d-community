# M64 主循环独立复核

结论：本轮受控 FP8 优化与真实模型验证完成，候选**不采用**。只读审查基于原请求、固定源码与构建、原始 GPU 计数 CSV、真实模型 Nsight SQLite、三臂原始 API JSONL 和服务快照；没有 SSH 或 GPU 操作。

- 数值门槛：13 组、688 次全输出逐位比较和 105 次换输入 Graph replay 通过。2×4 v2 的 scale 双写由完整 CTA 地址重建发现，v3 修正为 128 地址各一次；实际尾块另经 GPU 逐位门槛。
- 官方完整链：M16160 展示中位耗时为官方 GEMM+V2 10.6286ms、新融合+pack 11.3061ms、同设置旧 4×2 融合 11.6133ms；新比官方慢 6.36% 是逐轮配对比值中位数，展示中位数之比为 6.37%。四个 M 均未超过官方。NCU shared load wavefront 约为旧融合的 0.691×，但完整链 DRAM/L2 基本不变；时钟变化使核级时长无法直接解释为周期收益。
- 真实模型：原始 SQLite 中私有 GEMM、pack 各 65 次，均为成功直接 CUDA launch；同次身份记录有 65 个注册 M16160 模块。实际模型未见 Graph replay，且单条 witness 不能证明 12 条性能请求逐条命中该 M。
- A/B/A：原始 JSONL 离线复算 12 对同输入 prefill TTFT 的候选变化中位为 −2.627342694%（退化），A2/A1 漂移 +0.558749129%；decode 中位 106.767/104.636/106.756 tok/s。B 的六条 decode 正文 hash 与两个基线均不同；不能把 decode 差额作纯算子因果归因。每臂同镜像、命令、12GiB KV 和 11,589,593,600B packed 副本。
- 服务：119 次 embedding 健康/身份采样无异常，最终两次功能调用均 200、1024 维有限值；原 27B/9B/ASR 保持停止，自有实验容器已清空。此为离散观察，不证明连续 SLA。
